# Порівняння функцій жадібного алгоритму і динамічного програмування для розрахунку решти

Набір монет: `[50, 25, 10, 5, 2, 1]`. 
Для суми `113` обидві функції повертають:

```python
{50: 2, 10: 1, 2: 1, 1: 1}
```

Разом це 5 монет.

## Жадібний алгоритм

Функція жадібного алгоритму перебирає номінали від найбільшого до найменшого. Для кожного номіналу ми визначаємо кількість монет за допомогою цілочисельного ділення. Остача від ділення визначає суму, яку ще потрібно видати. Кількість монет для одного номіналу обчислюється одразу.

## Динамічне програмування

Функція динамічного програмування обчислює мінімальну кількість монет для кожної суми від 0 до заданої суми. Для кожного доступного номіналу перевіряємо мінімальну кількість монет для суми без цієї монети та додаємо одну монету. Зберігаємо найменшу кількість монет і номінал, який дав цей результат. Після заповнення списків визначаємо набір монет, послідовно віднімаючи збережений номінал від залишку суми.

Для заданих номіналів жадібний алгоритм є ефективнішим: він знаходить мінімальну кількість монет і працює швидше для всіх перевірених сум. Кількість кроків у циклі залежить від кількості номіналів, а не від суми. Тому час виконання залишається приблизно однаковим.

Динамічний алгоритм зі збільшенням суми потребує більше часу та пам’яті, оскільки заповнює два списки довжиною сума + 1 і для кожної суми перевіряє всі номінали. Для дуже великих сум зберігання всіх проміжних результатів може стати обмеженням.

Цей висновок працює для заданого оптимального списку доступник монет.
