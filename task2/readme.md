# Обчислення значення інтеграла функції методом Монте-Карло

Функція та межі інтегрування:
- `f(x) = x²`
- `a, b = [0, 2]`

Генеруємо точки в прямокутнику та рахуємо частку точок, які потрапили під графік.
Область під графіком повністю міститься в прямокутнику шириною `2` та висотою `4` з площею `8`.

Результат:
- Загальна кількість точок: 150000
- Кількість точок під графіком: 49964
- Інтеграл за методом Монте-Карло: 2.6647466667


## Порівняння з quad

| | |
:----------- | :----------------------------
| Метод Монте-Карло | 2.6647466667
| Результат quad | 2.6666666667
| Абсолютна різниця з quad | 0.0019200000
| Відносна різниця з quad | 0.072000%


Метод Монте-Карло дав результат близький до результату `quad` для 150000 випадкових точок.

Результат Монте-Карло залежить від випадково згенерованих точок. Зі збільшенням їх кількості похибка зменшується.
